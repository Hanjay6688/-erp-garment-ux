# Current versioned target integration preparation

The full current chain already contains target v1. B's versioned source and
consumer installers intentionally require absent namespaces and pre-target
function bodies; applying those fresh-only installers here would fail.

The A adapter first verifies the real scoped-model predecessor, then adds the
unchanged B evaluation selector and physical binding. It retains the existing
legacy target source, projection and consumer objects. Exact B SQL adds seven
batched source functions and two versioned consumer functions; 14 of 21 named
hook bodies change and seven stay byte-identical. Existing function authority,
all 22 catalog groups, every table row and every sequence remain bound.

Pre-use inverse restores the captured definitions and drops only the newly
declared objects with RESTRICT. The complete-chain used guard runs before any
inverse DDL. Posted history, model policy and stored financial results are not
rewritten. No default installer or owner activation policy is created.

Local catalog controls use an actual predecessor backup and synthetic new
catalog rows. Native runtime qualification, composed used restore, permission
withdrawal and real Auth/browser coverage remain open. SOURCE and an execution
workflow are not supplied by this preparation. The earlier local assumption
that all 21 hooks change is retained as a first-failure receipt.
