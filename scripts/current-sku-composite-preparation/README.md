# Prepared SKU bridge to the current Afui and Mandor parent

The standalone moving-average composition expects the older SKU27 state.
The current Mandor assembly instead owns its complete Afui state and Mandor
delta. Calling the old verifier on that installation, or projecting its
catalogue back into the old shape, would discard current-parent authority.

This preparation derives six exact source substitutions from the unchanged
13,619-byte SKU composition. It selects the explicit current parent, uses a
distinct source contract, binds the complete nested parent state and verifier
proof, requires the complete actual pre-child catalogue to equal the current
parent, and takes the original pre-install data from the actual Afui state.
SQL, roles, metadata transitions, physical allocation, valuation, used guards,
the narrow inverse, and the full inverse remain unchanged. After the narrow
inverse the original child code calls the current parent verifier again.

All ten admission values remain `None`. Importing the preparation cannot run
an installation, open a connection, or activate a workflow. The loader first
requires exact Root-accepted Mandor17/all-five and SKU Native5/all-five bytes,
accepted source graphs, the exact parent assembly source and an owning runtime entry. It then checks the actual
module paths, the frozen child head/tree, unchanged tracked source and all
preparation file pins. These are prerequisites for a future composite run,
not a replacement for that run.

The six local controls use explicitly modeled interfaces and source ASTs.
They prove refusal ordering, complete nested-state binding and unchanged
inverse bodies. They provide no actual ERP, session, HTTP, browser, restored
database or independent-audit acceptance.

Before activation, fill the gates only from actual accepted Originals; align
the proposed Root receipt fields with the reviewed terminal package; materialize
the exact accepted child at `../qualified-sku-moving-average`; and qualify the
combined current parent and child through the owning complete package. All
five SKU Native cases, concurrent/current-permission cases, actual readers,
unused and used inverses, full rows/sequences/roles/raw public/advisors and the
complete backup restore remain required. UI integration and Global dispatch
review remain separate candidates until tested together.
