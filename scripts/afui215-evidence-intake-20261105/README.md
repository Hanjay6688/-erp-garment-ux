# Exact terminal Afui215 evidence intake

This read-only collector is prepared separately from the frozen financial run.
It refuses any active source run, foreign head, job, branch, attempt or final
artifact. It enumerates every artifact API page and selects the one canonical
final archive by its exact name. The official API supplies the complete SHA
and byte size; all bytes and every ZIP CRC are verified before publication.

The complete archive is retained first in at most sixteen 400 MiB parts, each
with the whole source manifest. Complete original report/log receipts are
retained separately. A log failure cannot erase the verified archive parts.
No ERP source is imported, no SQL is performed and no case/Root is accepted.
The authenticated GitHub API header never crosses an archive redirect.

The push trigger only matches astra-a/afui215-evidence-intake-20261105.
The preparation branch does not start the collector. Activate the read-only
branch only after the one fixed owning run is terminal and its final artifact
is present. Financial main, source branch, timers and database stay unchanged.
