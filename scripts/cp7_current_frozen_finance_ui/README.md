Reliable data adalah dewa. Keuangan termasuk laporan, stok dan HPP adalah raja.

Sumber caller B f843e4ce disimpan byte-exact di vendor, beserta seluruh import,
parser waktu mikrodetik dan delapan berkas tes asli. B_SOURCE.json mencatat
setiap berkas. Tidak memasang bridge backend B atau mengubah backend A yang
terkualifikasi. Ini host disposable terisolasi; default aplikasi belum diadopsi.

build.mjs mengarahkan hanya import client pada dua panel frozen B ke client.ts.
AuthProvider, AuthGate, parser, penyimpanan, Web Locks, halaman dan pemeriksaan
hasil tetap berasal dari sumber B yang tepat. Adapter mengirim STAGED ke
endpoint finance A pada request, reopen dan revalidasi DONE. Tanpa mode tetap
operasional. DEFERRED eksplisit diubah menjadi ketiadaan mode hanya pada payload
transport, sesuai kontrak A; byte permintaan tersimpan tidak berubah. Mode lain
ditolak sebelum jaringan. Tidak ada fallback endpoint setelah gagal.

Tes lokal menguji caller asli dengan transport terkendali dan delapan suite B.
Tes tersebut bukan bukti login/database/pabrik aktual. Build hanya membuktikan
closure browser dan kedua import terarah, bukan hasil keuangan server. Bukti
Auth/browser baru harus memakai backend A lengkap dan Original baru, termasuk
restore/CP6/advisor. Browser6 regresi yang sedang berjalan bukan kredit host ini.
