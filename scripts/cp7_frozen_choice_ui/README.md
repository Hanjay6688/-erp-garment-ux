# Prepared frozen candidate and confirmation UI

Explicit disposable entry using actual Auth identity and existing runtime client.
No default application import, shared installer, SQL, type registry or F05 route
change. NativeFrozenAnalogPanel accepts an already admitted FROZEN_V2 context;
old or foreign contexts fail before RPC. It uses the explicit v2 reader and
shows frozen provenance, physical-size candidates and all pages. Choice controls
require manage permission, a reason, scale and deliberate review.

Exact commands are durable before send and retain actor, method, UUID, payload
and original review across reload, source changes and every error. A committed
receipt can be recovered even after its source archive expires. Clear only after
a validated response; no automatic discard or replacement on source refusal.
Identity/access/source changes retire late replies; access denial removes visible
private data. Actual database access checks remain authoritative.

Local: 152 tests across seven files (23 new DOM journeys), dedicated TypeScript,
source serving and workflow shell parse PASS. First local failures retained in
the preparation receipt. Four real Chromium UI journeys are prepared with
controlled identity/RPC; actual browser, real Auth/Native and default adoption
still require their own complete evidence. No production_go or factory SLA.
