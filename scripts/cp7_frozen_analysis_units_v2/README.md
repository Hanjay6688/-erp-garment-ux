# Frozen unit adapter — private, unqualified preparation

The first HIST_PREP unit derives inputs from the immutable frozen capsule and
stores them once in the existing Native target_rows work table. Later units
check job/actor/request/run/query/capture/capsule/producer bindings and the
entire cached input hash before using a local reference overlay. Missing,
foreign or changed cache data refuses; no path recaptures stock. The Native
job reference remains immutable. Old references return through the old path.

The prepared outer run hook changes exactly one local-reference assignment in
the actual supply-patched Native function. PAGE/PAGE_INDEX early returns and
all existing computation remain. The prepared request is derived from the
bounded request; exact actor/UUID/query/method collision, fresh access after
the lock/capture, snapshot mark and target cap remain.

Eight derived replacements now prepare explicit fingerprint/source/input/
scenario/skeleton/workspace v1/v2 dispatch. A separate producer binds every
adapter function; v2 workspace coverage follows successful first-unit progress
and survives existing K3 cleanup. The private installer admits only its one
schema, eight new functions and eight exact replacements, keeps authority,
requires no running jobs, and refuses a pre-use inverse after usage. Its
dependency-view inverse remains savepoint-atomic. This installer has not yet
been qualified on Native; the prepared Native4 provider is not wired to F05.

Eleven local groups PASS on PGlite18.6 with the actual Native work-table DDL,
immutable triggers, K3 purge and step/status functions but controlled prepare
and unit bodies. The actual Native step subtransaction rolls back cache on
cancellation, increments its attempt, succeeds once on retry and refuses
changed access before any cache write.
This is not Native, access, compiler-math, request-latency or factory credit.
The initial fixture and wider coverage control both passed. A static signature
checker initially forgot that zero-argument SQL functions have no parameter
list; the checker was corrected, with all24 real signatures then compared.

No public facade, client contract, F05 route or default installer adopts this
adapter. Full request-to-pages Native qualification, current access/races,
public Auth/client adoption and after-use recovery remain required. Never
install a prepared replacement alone or infer readiness from generated SQL.
