# Kualifikasi Native40 gabungan A dan unit privat B

Mempertahankan seluruh36 kasus Native performance A, termasuk uang, stok, HPP,
riwayat, model, target dan kontrak retur. Menambah pemeriksaan katalog privat/
inverse dengan dependent view dan tiga tubuh kasus B yang sama: request-unit-
halaman/replay,1200 SKU x3 ukuran dengan hasil compiler seluruhnya dibandingkan,
dan posted-stale/arsip tidak berubah/purge. Batas8detik tidak diubah.

Katalog komponen B tidak dipasang/dilepas ulang di dalam kasus. Pemasang penuh A
memeriksa inverse semua22 kelompok/baris/sequence sebelum pemasangan kedua;
kasus privat memeriksa penolakan dependent view yang atomik. Hanya satu inverse
pemakaian di tubuh kasus stale diarahkan ke composer penuh dengan kode penolakan
penuhnya. Kontrol AST menjaga tiga tubuh bisnis B dan semua helper tetap sama.

Sumber A sebelumnya dan seluruh pemeriksa/prasyaratnya tetap dijalankan utuh.
Empat Original tambahan wajib byte-exact: A performance Native36 pada88f36937,
B binary4/capsule4 padae33, B privateunits4 pada10a. Semua sumber B dicek di
checkout10a tersendiri; tidak ada pengecualian pin A lama. SHA SOURCE seluruh
kandidat, ketiga gates sumber B, bukti pemulihan, CP6 dan advisor wajib cocok.

Fixture3602 target di sini membuktikan operasi privat. Itu belum membuktikan
keuangan resmi pada volume pabrik, AuthHTTP, browser, race, cron atau aktivasi
bawaan. Seluruh itu masih terbuka; production_go=false dan belum audit independen.
