# Request gabungan A/B

Adapter ini mempertahankan seluruh47 sumber B asal byte-identik. `render.py` menerapkan patch finance A yang sama ke predecessor dan final request B, dengan manifest before/after eksplisit. Hanya legacy request berubah dari SQL B; bounded request tetap tepat3kolom dan DEFERRED. Perubahan anchor atau manifest ditolak.

Pemasangan dalam transaksi/envelopelock milik `cp7_ab_bounded_chain`: schedule → boundedhistory → fullstockreference → ABbounded. Verifier tiap tahap dijalankan pada katalog nyata sebelum tahap berikutnya; seluruh22 kelompok akhir dicocokkan. Invers berbalik setelah globalusedguard sebelum DDL pertama. Sesudah dipakai memerlukan backup/restore utuh, bukan menghapus job/receipt.

Uji lokal: patch finance/initial komutatif, semua SQL B selain legacyrequest persis,3mutasi anchor ditolak. Ini belum bukti Native/produksi; lihat Original qualifier Native12 dan usedrestore.
