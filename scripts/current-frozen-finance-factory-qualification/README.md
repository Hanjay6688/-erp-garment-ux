Kandidat ini belum SOURCE-bound dan belum dijalankan. Sebelum binding wajib
Native45 privat lulus aktual, enam suite performance baseline lengkap lulus,
dan Original factorydaabINCOMPLETE tetap dipertahankan sebagai kegagalan.
Native45 SOURCE aktual nantinya digabung tanpa rebase ke cabang persiapan ini;
sumber/prasyarat kemudian diperiksa lagi utuh sebelum DB.

Fixture tanggal terkoreksi sama persis (SHA6dceb87a...). Seluruh63assertion
runner/fixture/probe dipertahankan. Hanya composer, modul helper permintaan
privat, label kasus/artifact dan label metadata mode yang diganti. Transport
menggunakan dua endpoint privat dari Native45; tidak mengklaim pemakaian
publicRPC atau AuthHTTP. Tidak ada perubahan saldo, stok, HPP, Oracle24metrik,
signature pembukuan, UNKNOWN, cakupan semua target/halaman atau tanggal fixture.

Jadwal menit asli/60transaksi dibatasi8detik/300detik keseluruhan tetap sama;
tidak ada tick manual, frekuensi jadwal baru, clock dipercepat atau progres
job yang ditulis langsung. Restore baseline seluruh22katalog/baris/sequence,
CP6, advisor dan semua5gate tetap wajib. Enam hasil performance lama dipakai
sebagai bukti baseline, bukan kelulusan perubahan privat ini. Tiga kontrol
negatif sumber, seluruh63assertion dan43bashstep diperiksa lokal, tanpaDB.

PrivateNative45, private factory ini, Auth/race/browser/restore setelah dipakai,
dan adopsi aplikasi adalah lingkup bukti berbeda. Belum ada public/default
adoption, penerimaan independen atau production_go.
