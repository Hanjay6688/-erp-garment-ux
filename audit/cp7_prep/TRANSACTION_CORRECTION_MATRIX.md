## Kasus standar per baris (manifest draft)

Untuk setiap baris bernomor, tiga kasus wajib dengan ID `TCM-<nn>-<A|B|C>`:

- **A — koreksi sah selesai:** buat → post → koreksi/pengganti sah → baca ulang semua buku: dokumen asal utuh, jurnal asal utuh, pengganti bertaut (lineage), stok/HPP/AP/AR/laporan per tanggal sesuai expected yang dihitung terpisah (Decimal, bukan helper produk).
- **B — terhalang dengan petunjuk:** buat ketergantungan lanjutan (pembayaran/retur/potong/pemakaian), coba koreksi/hapus → ditolak dengan kode Native; UI menampilkan nomor dokumen penghalang, jenisnya, halaman tujuan, dan urutan dari ketergantungan terakhir ke asal; tidak ada efek tersisa (INV-C06).
- **C — posted immutable:** `UPDATE`/`DELETE` langsung pada dokumen/jurnal/mutasi posted ditolak untuk peran admin aplikasi (INV-K07); hanya pembalikan/pengganti yang menulis baris baru.

Baris `n/a` (buku turunan, master, laporan) memakai kasus **D — buka sumber:** baris turunan membuka dokumen sumber yang tepat; target hilang → menolak, bukan menampilkan dokumen lain.
