# [bersama] Header dan navigasi HP

Pemeriksaan gambar aktual4025 menunjukkan badge data simulasi bertumpuk dengan judul pada HP. B menerapkan koreksi tampilan bersama dalam penugasan UI owner: header dua baris, label mode tetap terlihat, identitas/sesi tetap tersedia, dan label pintasan Dashboard dipendekkan menjadi Beranda. Route, permission key, pemeriksaan akses dan fungsi navigasi sama. Ikon pencarian header yang sebelumnya tidak memiliki aksi disembunyikan pada HP agar ruang diberikan ke judul dan sesi; pencarian halaman tetap tersedia.

Patch dibatasi ke App UI, CSS header, dan harapan label tes navigasi. A tetap pemilik integrasi akhir; ambil hunk UI setelah mencocokkan App terbaru. Kandidat pertama dan seluruh arsip gagal tetap disimpan; tidak ada perubahan SQL, ledger, stok, HPP atau kontrak transaksi.
