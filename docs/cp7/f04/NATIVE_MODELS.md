The public producer admits only an own immutable Native demand-history run, a real captured target and an explicitly selected horizon. It never accepts observations, predictions, model parameters, policy, actor or completeness from the browser. Current Ops permissions are checked before and after the actual request lock and before returning either a cached result or archive. Two public RPCs delegate to the existing no-login capture principal; private registry, evaluations and kernels remain unavailable to anonymous, authenticated and service roles.

Past knowledge comes from actual immutable Native history-capture times. A current retrospective ledger is not relabelled as information known before an old forecast. Consecutive identical observations retain their first actual knowledge time; changes and returns to earlier values remain distinct revisions. Unknown availability and stockout periods retain null training values. No current capture or future capture is inserted into an older result. The registry is first recorded at real installation time and is immutable; it cannot qualify a model configuration as known before it existed.

The fixed technical proposal compares mean, naive, moving mean, SES, damped Holt, seasonal naive, SBA and TSB. Three complete chronological folds share the selected horizon. Improvement must be strict, with bias and horizon-error guards; ties retain the baseline. The outer holdout is computed after selection and cannot select or tune a model. The proposal is labelled separately from an owner service target. Missing chronology, late registry knowledge and missing complete folds keep the baseline with an explicit reason. A recommendation cannot activate a registry entry, change production targets or apply a plan.

The UI is reachable from the actual Native demand table. It starts with a blank horizon, retires all source results during each read, stores only the pending UUID/query, replays that exact request after reply loss/remount, preserves the operator horizon on scope invalidation and rejects late replies. Current403 removes the model result and refreshes the parent FG/HPP through current authorization. Returned forecasts and scores are decimal strings; an absent value is never displayed as zero.
