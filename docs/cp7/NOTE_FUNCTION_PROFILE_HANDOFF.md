## Raw measurements and interpretation

The instrument reads pg_catalog.pg_stat_xact_user_functions immediately before and after the owning correction, before financial/book observation. Only erp, cp7_* and the exact public owning RPC are included. OID, schema/name/identity arguments, call count, inclusive elapsed time and self elapsed time are retained in both original arrays. No SQL body, Native arguments, credential or raw exception context is emitted. Over1000 rows is refused rather than truncated.

scripts/cp7_note_command_function_profile.py validates unique/stable OIDs, exact identities, finite nonnegative counters and nondecreasing deltas. A completed command requires exactly one observed call of the original public correction. It ranks self elapsed times and keeps the root inclusive time separately; inclusive parent and child times are never summed. The parser's exact SHA256 is retained in the actual HTTP emission.

These are elapsed counters for completed tracked calls, not CPU samples or SQL-plan attribution. SQL functions that PostgreSQL inlines are not included. Interrupted commands retain explicitly partial counters, possibly including exception unwind; they cannot claim a complete command duration. Tracking adds overhead, and the fixed comparison order also permits cache/order effects. One measurement cannot establish a timeout cause, production throughput, factory accuracy or an SLA. No timeout increase, authority cache, removed guard or formula change is justified by this candidate.
