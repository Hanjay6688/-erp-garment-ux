## 3. Binding-detail decisions to note (none deviates from the listed names)
- `jobs.reference` holds the captured source (as required); immutability of the fixed job columns is a column-list trigger (no detoast compare per unit). `cp7_analysis_stage.pages(run_id, idx, …)` as required. The header lives in `headers` (plus `page_sets` written last) — `page_sets` is the "page index".
- `plan_final` becomes true at ANA_META (the pages' number is byte-adaptive); the plan grows at HIST_PREP, NET_PREP, ANA_META.
- Status `failure` = `{unit, sqlstate, code}` exactly; `failure_message` is a private column only. `run_id`/`failure` keys present with `null` when not DONE/FAILED (the single job's convention). Timestamps rendered as the prototype did (`to_jsonb(timestamptz)`, UTC). `checked_at` = the current source's `captured_at`.
- `step(uuid, jsonb default null)`: the access check runs inside the row lock, so a concurrent caller still gets `worker_active` immediately; `step_request` re-checks access after the unit (42501, nothing kept) as `analysis-jobs.run` does.
- Page envelope reserve 4,096 bytes: a target whose items exceed `page_utf8_bytes − 4096` refuses.
