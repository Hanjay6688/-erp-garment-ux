## Contract decisions that depend on agent P's SQL (please align or tell me)
1. Job status: `run_id`/`failure` are accepted **absent or null** when not applicable (the prototype's `jsonb_build_object` emits null); `failure` may carry an extra string `message` (prototype shape); `stage` may be null only when not RUNNING; `stage_index` 1..`stage_count` ≤ `unit_count`; `targets_total` may be null before the plan is final, must be set on DONE; `worker_active` boolean if present. Any other key (e.g. the prototype's `job_id`) is refused — the product status must emit exactly the §10 fields + `contract_version: 'cp7.native-analysis-staged-job.v1'`.
2. Instants (`captured_at`, `last_progress_at`, `checked_at`): ISO 8601 with `Z` or `±hh:mm`, up to 6 fractional digits (either jsonb timestamptz output or the single job's `…Z` format works).
3. `identity_hash` for a run with 0 pages = sha256(header_sha256) (the §10 formula's `string_agg` over no rows would be NULL in SQL — P must coalesce).
4. Page set `reference` is compared with the DONE status `reference` (source_hash equal, captured_at equal by instant); `analysis_header.snapshot.source_hash` is NOT required to equal `reference.source_hash` (open question whether they are the same fingerprint).
5. Source check: required `{source_state, checked_at}`; optional `contract_version` (cp7.*.vN) and `run_id` (= the run) accepted; anything else refused.
6. Over-cap hint codes: `CP7_PLANNING_CAPTURE_INCOMPLETE` (history source > 1000 products turns INCOMPLETE), `CP7_PLANNING_HISTORY_GRID_LIMIT`, `CP7_NETTING_MATCH_SOURCE_LIMIT`, `CP7_NETTING_WORK_LIMIT`, `CP7_SUPPLY_GLOBAL_SCOPE_LIMIT`, `CP7_BASELINE_ALLOCATION_LIMIT`. Staged failure texts cover `CP7_ANALYSIS_STAGE_STOPPED`, `CP7_ANALYSIS_ACCESS_CHANGED`, `CP7_ANALYSIS_PAGE_BODY_LIMIT`, `CP7_ANALYSIS_JOB_ERROR` and the netting/history codes; unknown codes shown raw.
7. Target ranges are 1-based (`target_lo` of page 0 = 1), as the prototype SQL (`expect integer:=1`) and §10's "Target 501–1.000".
8. A DONE staged run is not remembered in the local archive and not listed by the server archive (whole readers refuse it); after the stored key is removed, a reload cannot reopen it — an archive of staged runs needs a server listing (open).
